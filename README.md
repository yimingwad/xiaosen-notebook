# 小森手账 xiaosen‑notebook
✨ 把日子，轻轻收进木屋｜治愈系Windows桌面手账软件
> 版本 v1.0.0｜Windows10 / Windows11｜完全离线，无需注册账号

## ✨ 主要功能
- 📝 手账日记自动保存，实时字数统计，写作星光小特效
- 🐱 小动物互动：猫咪、兔子、小鸟随季节天气做出动作反馈
- 🍂 四季氛围切换：春、夏、秋、冬画面与角色装扮
- 🌤️ 天气系统：手动切换晴/阴/雨/雪，支持联网获取实时天气
- 🎵 本地音乐播放器，导入本机音频做背景音
- 💾 本地全部数据存储，支持Markdown批量导出备份
- 📅 往日时光历史记录翻阅，补写过去日期手账

## 📦 获取程序、源码与完整使用文档
> 全部文件请前往右侧 **[Releases](../../releases)** 页面下载
- 可执行程序：`小森手账-1.0.0.exe`
- 完整源码压缩包：源码.zip
- 📄 **完整PDF操作手册：小森手账-使用说明.pdf**

## 🚀 快速上手
1. 双击 exe 启动程序
2. Windows拦截提示：点击**更多信息 → 仍要运行**
3. 打开软件即可新建手账、记录日常
> 首次启动自动创建数据目录：`%APPDATA%\小森手账`，日记、音乐、配置全部保存在本机。

## 📂 数据与备份
- 手账、音乐、配置存放路径：`%APPDATA%\小森手账`
- 支持一键导出Markdown备份；换电脑直接复制文件夹恢复数据
> 隐私说明：软件不会上传日记数据，仅实时天气功能需要联网。

## ❓常见问题
1. 没有音乐：将mp3放入`%APPDATA%\小森手账\music`文件夹后重启软件
2. 天气获取失败：手动切换天气即可，其余功能不受影响
3. 程序被阻止：属于未签名程序，选择仍要运行
